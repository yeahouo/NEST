Late · 晚归台账

晚归与夜不归宿台账

判定基准 6:00-23:30（第七条）：在该时段之外出入属晚归，整夜未归为夜不归宿；断电时间 23:30 / 次日 6:00 只作制度提示，不参与判定。 来源 source：门禁刷卡 card（由园区门禁系统导出后导入）、查房 check、上报 report。处理只能到批评教育 / 通报批评 / 记录备查或建议等级，正式处分走学校程序，本平台只登记与跟踪。 辅导员账号只能看到自己名下学生的记录（后端按 counselor_id 收窄）。

Violation · 违规台账

违规台账与条款引用

违规类型对齐《学生违纪处分管理规定》第四十一条园区违规十三类与第四十二条消防条款；每条必须引用依据条文（ruleRef）， 处理建议只到批评教育 education / 通报批评 circulated / 警告 warning / 严重警告 serious_warning / 记录备查 recorded， 处分决定由学校按《学生违纪处分管理规定》程序作出，本平台只登记与跟踪。辅导员只能看自己名下学生的台账。

Civil · 文明宿舍

文明宿舍评比与公示

按《厦门大学嘉庚学院学生园区管理规定》第十七条「定期组织对宿舍内务进行检查和评分，并及时在全校公布；学校每学期开展一次校级「文明宿舍」评比」： 计算按学期汇总已公布批次的均分、给出楼栋内排名；名额与比例学校未公布，系统不自动截断名额，获奖由管理员人工确认。 公示对学生与教职工登录可见，只露楼栋 / 房号 / 均分 / 等级，不含姓名与学号。

Activity · 社区活动

社区活动管理与报名审核 / 签到

活动类型对齐学校实际举办的赛事（园区文化节、宿舍风采大赛、宿舍吉尼斯挑战赛、设计大赛、志愿服务等）；学校办赛为「第一轮探访 → 决赛」两阶段， 平台体现为活动说明与报名 → 审核 → 签到（已报名 signed → 已通过 approved → 已参加 attended / 未参加 absent）。 同一活动同一学生只允许报名一次（唯一约束），获奖等级与积分只由管理员登记；草稿活动学生端不可见。
