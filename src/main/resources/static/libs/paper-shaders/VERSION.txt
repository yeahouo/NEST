API notes (read from the vendored source, 2026-10-15)
-----------------------------------------------------
  new ShaderMount(parentElement, fragmentShader, uniforms, webGlContextAttributes,
                  speed = 0, frame = 0, minPixelRatio = 2,
                  maxPixelCount = 1920*1080*4, mipmaps = [])
    * prepends its own <canvas> into parentElement and injects a style[data-paper-shader]
      with `@layer paper-shaders` rules: parent becomes position:relative + isolation:isolate,
      canvas becomes position:absolute; inset:0; z-index:-1; width/height:100%.
      => the parent MUST NOT paint its own background, or the canvas hides behind it.
    * throws `Paper Shaders: WebGL is not supported in this browser` when webgl2 is missing
      => always wrap in try/catch and keep a CSS fallback.
    * speed = 0 stops the rAF loop entirely (static shader, no recurring cost).
    * u_time is written by the mount as currentFrame * 1e-3; u_resolution / u_pixelRatio too.
    * array uniforms must be passed as ARRAY OF ARRAYS: [[r,g,b,a], ...]
      (a flat array only works for length 2/3/4; 20 floats would silently not be set).
    * unknown uniform keys log `Uniform location for <key> not found` -> pass only real uniforms.

  mesh-gradient uniforms: u_colors (vec4[10], max 10 colors), u_colorsCount,
  u_distortion, u_swirl, u_grainMixer, u_grainOverlay

  *** TRAP (found 2026-10-15 with gl.readPixels, cost us a silently blank canvas) ***
  The shared VERTEX shader also needs the SIZING uniforms, and the core package does NOT
  fill them for you (the upstream React wrapper does):
      u_fit (=ShaderFitOptions.contain=1) u_scale(1) u_rotation(0) u_offsetX/u_offsetY(0)
      u_originX/u_originY(0.5) u_worldWidth/u_worldHeight(0) u_imageAspectRatio(1)
  Skip them and u_scale defaults to 0; the vertex shader does `v_objectUV /= u_scale`
  -> Inf/NaN -> the fragment output is written as fully transparent black.
  Symptom: the page looks fine (CSS still paints) but the canvas draws NOTHING, and no
  console error/warning appears. Proof command: tools\check-art.ps1 (its first two
  assertions mount the same shader twice, with and without SIZING, and read pixels back).
  `import { ShaderFitOptions, defaultObjectSizing } from '../shader-sizing.js'` to build them.
