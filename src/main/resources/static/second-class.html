学工平台 · Second class

学时与学分口径由学校设定；本平台只登记、初审与认定，不代填任何标准。

申报活动

—

申报学时默认取活动学时，可以改小但不得超过活动学时，单条也不超过 100 学时。提交后进入待初审，由辅导员初审、管理员认定。

自主申报（无活动）

适用于没有在册活动的成果（证书、竞赛、讲座记录等）。标题与证明材料链接都必须填，否则后端会拒收； 学时口径由学校设定，未设置标准时由初审 / 认定环节裁定。

修改后重新提交

—

请按退回原因改好后重交；重交后状态回到待初审，需要辅导员重新初审。只改你要改的项，留空的项按原值保留。
