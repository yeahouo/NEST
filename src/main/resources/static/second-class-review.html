§ 29 · Staff / Second Class

第二课堂审核与台账

覆盖申报审核（辅导员初审 → 管理员认定）、板块台账、活动台账与 CSV 导出。两级审核不假装四级： 「团支部初审 + 院系复核」合并为一次辅导员初审，「校级认定」由管理员代表校团委执行，页面只呈现这两步。

状态口径：submitted 待初审 → counselor_approved 待认定 → confirmed 已认定（终态）； 待认定也可 → rejected 已否定（终态）；待初审可 → returned 已退回（学生改后重交）。所有状态流转走 CAS，影响行数为 0 时后端返回 400「状态已变化，请刷新后重试」，本页把 message 原样显示。

权限口径：辅导员（teacher）只能对名下学生的申报做初审（未分派辅导员的学生按全校可见），不能认定、不能否定、不能维护板块与活动； 团委（admin）可代审、可认定 / 否定、可维护板块台账与活动台账、可导出全校数据。相关按钮对本角色置灰并标注原因。

数值口径：板块的「要求学时 / 学年上限 / 学分折算系数」全部由学校设定，未设置时显示「未设置」，接口返回 null（不是 0），系统不代填任何国家或校级标准。学年上限不硬截断，只在学生端汇总里提示「计入上限 / 超出多少」。

Categories · 板块

板块台账

S26 只规定了「第二课堂成绩单」这一制度，没有给出任何学时 / 学分 / 学年上限的数值，所以这三列完全由学校设定。 留空表示未设置：接口返回 null，页面显示「未设置」，保存时显式传 null（不是 0）。 PUT 是整体覆盖，每次三条数值一起提交，留空的就会被清成「未设置」。

学时与学分口径由学校设定：未设置时显示「未设置」，系统不代填任何标准。

认定申报

—

学分留空 = 由后端按板块换算规则计算（学时 × creditPerHour，四舍五入两位小数）； 板块未设置 creditPerHour 时换算结果为空，需手填或先到板块台账设置系数。 认定是终态，认定后不能再改（要改只能由学生重新申报）。

新增板块

三个数值口径留空 = 未设置，系统不代填任何标准；保存时留空会显式传 null（不是 0），台账显示「未设置」。 编码格式 ^[A-Z][A-Z0-9_]{1,31}$：大写字母开头，只含大写字母 / 数字 / 下划线，2-32 位；编码创建后不可修改。

新建活动

日期格式 yyyy-MM-dd；组织层级取 school 校级 / college 院级 / class 班级 / other 其他。 单场活动学时须在 0-100 之间（数值由学校设定，超过请拆分为多场）。
