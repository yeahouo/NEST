§ 26 · Student / Club

学生社团 · 我的社团

本页面向学生本人：查看我加入的社团与我在社团中的角色、我所在社团的年审结果与星级评定结果（只读）， 以及公示中的社团年审 / 星级评定结果名单。 本页不提供年审材料提交、星级申报或评审操作 —— 那些属于社团管理端。

年审结果与星级由校团委社团管理部 / 学生社团指导中心评定，依据《厦门大学嘉庚学院学生社团建设管理办法》， 本平台只登记与公示结果，不做任何自动判定，也不给出判定建议。

「我的角色」取自社团成员名册（club_member.role：负责人 / 成员）；接口未返回角色时不臆测，显示为「—」。 指导老师字段为社团自行填报内容，学校公示口径中未规定该字段的构成。 社团类别共六类：创新创业类、思想政治类、文化体育类、学术科技类、志愿公益类、自律互助类。

数据来自 GET /api/club/reviews（只读）。年审结果取值为 合格 / 不合格 / 注销， 与 S25a 年审公示表「年审结果」一列口径一致。

社团名称 学年 年审结果 挂靠单位意见 提交时间 审核时间

你所在的社团暂无年审结果记录。

年审依据《厦门大学嘉庚学院学生社团建设管理办法》，审查聚焦四项：组织架构合理性、骨干成员胜任力、学期活动运行质量、经费使用合规性。 「合格 / 不合格 / 注销」的判定标准原文未作规定，本平台只登记结论与材料，不给判定建议； 「未参加年审的后果」亦无来源，本平台不作提示。

社团名称 学年 评定星级 业务指导单位 依据说明 登记时间

你所在的社团暂无星级评定记录。

星级评定聚焦三项：校园文化传承、活动策划执行、社会实践参与。完整档位与升降细则无公开来源， 因此本页只呈现本次实有的三星级 / 四星级 / 五星级三档，不推算、不预告。 请注意与志愿者星级区分：志愿者星级（一~五星级志愿者，S21 第三十条）与学生社团星级（三星~五星级社团，S25b）是两套不同制度。

Publicity · 公示区

社团年审 / 星级评定公示

数据来自 GET /api/club/publicity，本页只展示公示中（open）的公示，公示期为 5 天。 公示明细含：社团名 / 结果或星级 / 业务指导单位（年审公示为挂靠单位）/ 社团类别。

对公示内容有异议的，请发邮件至 twh@xujc.com（共青团厦门大学嘉庚学院委员会社团管理部 / 厦门大学嘉庚学院学生社团指导中心）。

Read only · 只读说明

哪些事学生端不做

  • lock学生端不能提交年审材料，也不能提交星级评定申报 —— 这两件事属于社团管理端，由社团负责人与业务指导单位在管理端办理。
  • lock学生端不能修改年审结论或星级，只能查看校团委社团管理部 / 学生社团指导中心已评定的结果。
  • lock年审结果与星级由校团委社团管理部 / 学生社团指导中心评定，本平台不做任何自动资格判定，也不给出判定建议。
  • lock「合格 / 不合格 / 注销」的判定标准、「未参加年审的后果」、社团星级的完整档位与升降细则，原文均未规定或无来源，本平台不作推测与提示。
  • lock本页不导出名册或联系方式；公示区只按学校既有公示口径呈现社团名称与结果 / 星级。
