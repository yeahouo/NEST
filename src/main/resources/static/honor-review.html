Batch · 批次管理

评奖评优批次

—

状态流转：草稿 → 申报中（发布）→ 审核中（进入审核）→ 公示中（进入公示）→ 已结束。 名额与比例以当年评选文件为准，填写时请照抄文件口径，平台不作断言。

还没有批次：点「新建批次」创建后发布，学生端才会出现申报入口。

相关入口

insights 综测审核 自动核验读的是综测汇总：批次里配了 eval_term，才能自动判定「综测排名前 15%」。 military_tech 奖惩管理 校级以上荣誉称号次数与奖学金记录来自奖惩模块；数据不准先在这里更正。 volunteer_activism 困难认定管理 家庭经济困难认定与评优是两条线，互不作前置。 dashboard 返回工作台 教师工作台汇总待办与名下学生。
