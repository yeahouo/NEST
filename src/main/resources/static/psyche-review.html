Export · 脱敏导出

导出 CSV

三种导出：普查名单（可限定批次）、关注台账、预约排期。CSV 由后端生成，带 UTF-8 BOM（Excel 直接打开不乱码），姓名与学号已脱敏，预约导出不含主要咨询问题全文与中心内部备注。学生账号无导出权限。

已知边界：/api/psyche/export 未登录时返回 302 → 登录页；浏览器会跟随跳转，于是拿到的是登录页 HTML（Content-Type: text/html）而不是 CSV。本页用 Content-Type 兜住这种情况并提示重新登录，不会保存一个 .csv 后缀的 HTML 文件。导出接口不走统一 JSON 包裹（{code,message,data}），返回的是文件字节流。
