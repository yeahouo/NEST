# 前景与范围文档

## 1. 业务需求

### 1.1 背景

当前高校教学中，课堂管理主要依赖人工操作。教师需要手动管理学生签到、作业发布与批改、课程公告发布等日常教学事务，工作量大且效率低下。传统的线下管理模式存在信息传递不及时、数据统计困难、学生参与度难以量化等问题。与此同时，随着人工智能技术的快速发展，尤其是大语言模型和智能代理技术的成熟，为课堂教学管理提供了新的智能化解决方案的可能性。

本项目基于已有的课堂管理系统（CodeClass），在此基础上嵌入智能体功能，并完善代码中的空缺部分，打造一个面向厦门大学嘉庚学院的智能教学辅助平台。系统采用前后端分离的B/S架构，后端使用Spring Boot框架，前端使用HTML + Tailwind CSS + JavaScript，数据库采用MySQL，实现课程管理、作业管理、签到管理、公告管理、AI智能辅助等核心功能。

### 1.2 业务机遇

随着教育信息化和智能化的深入推进，高校课堂教学对智能化工具的需求日益增长。本项目的业务机遇主要体现在以下方面：

1. **教学管理效率提升**：通过信息化手段将传统线下教学管理线上化，教师可以更高效地管理课程、发布作业、组织签到，减少重复性劳动。
2. **AI智能体赋能**：嵌入智能体后，系统可以辅助教师进行作业批改建议、自动生成课堂总结、智能回答学生常见问题等，进一步减轻教师负担。
3. **学生学习体验改善**：学生可以随时在线查看作业要求、提交作业、查看成绩和反馈，及时了解课程动态，提升学习体验。
4. **数据驱动教学决策**：系统收集签到、作业提交、成绩等数据，为教师提供数据参考，辅助教学决策。

## 2. 范围与限制

### 2.1 第一版范围

**包含功能：**

- 用户注册与登录（支持学生、教师两种角色注册，教师注册需邀请码）
- 基于角色的访问控制（管理员、教师、学生三角色）
- 课程管理（创建、加入、查看、删除课程，课程码机制）
- 作业管理（创建、发布、提交、批改、查看成绩）
- 签到管理（发起签到、签到码签到、签到统计）
- 公告管理（发布、查看、编辑、删除公告）
- 个人中心（个人信息修改、密码修改、头像上传）
- 管理员后台（用户管理、课程管理、邀请码管理、数据仪表盘）
- AI智能体辅助（作业批改建议、智能问答）

**不包含功能：**

- 在线考试/测验模块
- 实时通讯/聊天功能
- 移动端App（仅Web端）
- 第三方平台集成（如微信、钉钉）
- 视频直播教学功能

 |                  | BR-13: 签到码必须与对应课程的签到会话完全匹配                            |
 |                  | BR-14: 学生必须是该课程的正式成员才能签到                                |

# 业务规则汇总

| 规则编号 | 规则名称           | 规则描述                                                           |
 | -------- | ------------------ | ------------------------------------------------------------------ |
 | BR-1     | 作业必填项         | 作业标题和截止时间为必填项                                         |

 | BR-9     | 签到码格式         | 签到码为6位随机数字                                                 |
 | BR-10    | 签到状态类型       | 签到状态包括：出勤、迟到、早退、旷课                                |
 | BR-11    | 签到状态修改       | 教师可手动修改学生的签到状态                                        |
 | BR-12    | 签到次数限制       | 每位学生对每个签到会话只能签到一次                                  |
 | BR-13    | 签到码匹配         | 签到码必须与对应课程的签到会话完全匹配                              |
 | BR-14    | 课程成员验证       | 学生必须是该课程的正式成员才能签到                                  |
