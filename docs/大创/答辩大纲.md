## 第 5 页 · 宿舍分配：算法链路

**讲什么**

## 第 7 页 · 创新点：缺失感知的分配（MAA）

**讲什么**
把「问卷可能残缺」当一等公民，而不是先插补再计算。三条**可证伪**命题：H1 缺失语义（未知维贡献记 0，而非均值补齐）、H2 可评估性门限（Cov/Eval 低于阈值时不得把分数当结论）、H3 信息价值 VOI（每格补采的期望增益，用来排「先问谁、问哪题」）〔docs/创新点-不确定感知的宿舍分配.md:24-74〕。为什么值得单独立题：论文里「准则没填」会退化成 ties，真实问卷的缺项是「观测没采到」，数学上不是同一件事〔同上:18、20〕。

**放什么图**
公式板：`c_ij = Σ w_d·c̃_d`、`Cov` / `Eval` 定义、`Δ_{i,d}` 期望增益；旁边一张「均值插补 vs 未知中性」的结果差异示意。

**关键数字**
- 8 个打分维权重：作息 .20 / 吸烟 .20 / 卫生 .14 / 外向 .10 / 学习噪声 .14 / 游戏噪声 .10 / 社交 .06 / 共享 .06〔同上:26-42〕

- 门限建议 `Cov < 0.15` 或 `Eval < 0.5`〔同上:54-56〕

## 第 9 页 · 证据二：同预算下 VOI 更会挑格子

**讲什么**
10% 催填预算下，按 VOI 挑格子比随机挑更能提升分配收益，比不补也更好。同时主动交出这条结论的限度：预算只补 103/1029 格，且 200 人里有 117 人的室友因此改变（59%）——所以结论是「VOI 更会挑格子」，不是「补 10% 就提升质量」〔docs/创新点-不确定感知的宿舍分配.md:188〕。

**放什么图**
配对差条形图（三条：voi−none / voi−random / mean−none），误差棒为 ±SD；右侧小表为预算扫描。

**关键数字**
- `voi − none` **+0.0021 ± 0.0060**（6/10 种子为正）〔同上:169〕
- `voi − random` **+0.0039 ± 0.0074**（8/10 种子为正）〔同上:171〕
- `mean − none` **−0.0001 ± 0.0043**（5/10）〔同上:189〕
- 预算 10% / 30% / 60% 时 `voi − random` 为 +0.0031 / +0.0053 / +0.0077〔同上:176-182〕
- **诚实边界**：补齐值取隐真值 `g`，测的是**收益上界**不是期望收益〔同上:74〕

## 第 10 页 · 证据三：插补能把 MAE 刷低，却买不到决策价值

**讲什么**
这是全场最反直觉的一页，也是最该讲的一页：`mean` 臂的 MAE 最低（0.4228，比 `voi` 的 0.4365 还低），但它的分配收益与「不补采」无法区分；而「最差那对」在三个预算档上都是 `mean` 最差——插补会把最差的一对**掩盖**成中等，真值补齐才会把它抬起来〔同上:182、189〕。P2 因此判为「无可测收益」而非「主动损害」〔同上:189〕。

**放什么图**
四臂指标表（none / random / voi / mean）+ 一张「最差那对随预算变化」的折线。

**关键数字**
- 四臂均值相容度：none 0.6475 / random 0.6457 / **voi 0.6496** / mean 0.6474〔同上:158-163〕
- 最差那对：none 0.1422 / voi 0.1179 / mean 0.1403〔同上:158-163〕
- MAE：mean **0.4228** < voi 0.4365〔同上:189〕
- 最差那对随预算（10/30/60%）：voi 0.1202 / 0.1115 / 0.1148；mean 0.1525 / 0.1483 / 0.1616〔同上:182〕

## 第 12 页 · 一次自我纠错（建议保留，评委最认这个）

**讲什么**
验收阶段我们查出自己的评估偏差：原模型用总体均值补齐缺失特征，等价于把「没回答问卷」算成「很合得来」，于是越不填问卷的学生越被判定为志同道合。改成「只对双方都填过的维度计算、一维都没填的对标为未知」后，NEST 在缺失数据上的绝对表现下降 3~4 个百分点，相对基线的领先随缺失率单调缩小。旧模型下那些更漂亮的数字，是我们自己在给自己发奖。结论一句话：**缺失数据没有免费午餐；系统能做的不是「数据缺失时依然准确」，而是不假装准确**〔docs/实验与验证.md:414〕；〔docs/结题材料/结题报告.md:35〕。
