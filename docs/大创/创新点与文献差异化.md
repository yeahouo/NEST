# 创新点与文献差异化

> 本文回答两个问题：**① 我们的宿舍分配算法到底原创在哪；② 和已有论文相比，哪些是借鉴、哪些是增量。**
> 诚实结论先说：**底层没有一个概念是我们发明的；但也没有任何一篇论文与我们的组合重合。我们的创新是「增量 + 针对性」，不是「发明」。**

- 相关深读：`docs/宿舍分配算法-文献对照.md`（B07 全文精读 + 逐项对照）、`docs/创新点-不确定感知的宿舍分配.md`（MAA 创新点全文）、`docs/superpowers/specs/2026-09-27-nest-dorm-assignment-design.md`（三项创新点原文）、`docs/实验与验证.md`（实测数字出处）。
- 本文所有数字取自上述文档与 `docs/实验与验证.md` 的仓库实测，不另造口径。

---

## 1. 一句话定位

**我们不做「假装精准的 AI 匹配」，我们做「诚实、可解释、可申诉、可证明差距的匹配」。**

这句话不是口号，是四个增量创新点共同落点的概括——而它恰好是央视 2025-09-28 调查 [《用 AI 匹配大学舍友：是「精准适配」还是「形式主义」？》](https://big5.cctv.com/gate/big5/news.cctv.cn/2025/09/28/ARTI3ppvDsiIwJNIhnkrvRNx250928.shtml) 所指「形式主义」的反面。答辩时可以直接甩出这句话，再展开下面四节。

---

## 2. 四个增量创新点（借鉴什么 → 增量什么）

设计文档 §3 写了三项创新点，MAA 文档补了第四项（最尖锐、且已落地+实测）。合起来是四个：

| # | 创新点 | 借鉴（已有人做） | 我们的增量 | 落点 |
|---|---|---|---|---|
| ① | **近稳定 + CP-SAT 上界裁判** | 「almost-stable」（最小化阻塞对）是成熟方向（TSC 论文，见 §3） | **不吹「稳定」**：容量 4 下零阻塞对通常不可达、判定 NP-hard；改成「最小化阻塞对 + 用 CP-SAT 小规模求上界，量化离最优多远」。把「分得好不好」从玄学打分变成可证明的数字 | `NestSolver` 管线 + `OptimalJudge`（CP-SAT 裁判） |
| ② | **可解释 + 反事实申诉** | 稳定匹配有 egalitarian 等公平准则；「解释」在 ML 里是通用诉求 | **四维解释**（约束命中 / 相容度分解 / 志愿层 / 对比层）+ 申诉时**固定其余人、局部重解**，回答「满足你会牺牲谁、整体目标下降多少」。**宿舍分配领域几乎无人做反事实申诉** | `ExplanationService` + `AppealService` |
| ③ | **不确定感知（MAA）** | 缺失值插补、LLM 抽特征都是常规做法 | **把缺失当一等公民**：未知=中性（不插补）、可评估性门限（Cov/Eval 判断「分数能不能当结论」）、信息价值 VOI（决定「催填谁」）。「承认不知道」而不是「猜一个数」 | `MissingnessAdvisor` + `RuleBasedCompatibility` + 管理端「补采建议」tab |
| ④ | **块分解并行** | 聚类（chameleon 等）做室友匹配早有 | 利用宿舍**硬约束结构**（性别×楼栋×专业大类）切块，块间并行、块内独立求解，**万级规模真能跑**（非 demo） | `BlockDecomposer` + ForkJoinPool 并行 |

> 第 ③ 项 MAA 是最尖锐、最成熟的一项：三条可证伪命题（H1 未知=中性、H2 可评估性门限、H3 信息价值 VOI）已配四臂实验，实测数字见 `docs/创新点-不确定感知的宿舍分配.md` §7，并已在宿舍管理端做成「补采建议」只读功能（§8）。

**读法**：每一篇只覆盖四个创新点里的**一个部件**，而且都是「方向层」——做近稳定的不做可解释，做 AI 匹配的不做近稳定，做系统的不做算法。**把「近稳定 + 可解释申诉 + 不确定感知 + 块分解 + 完整工程落地」拼成一条链并跑出实测数字的，检索三轮没有找到。**

## 4. 诚实边界（答辩别踩的坑）

1. **底层不原创**：稳定室友匹配是 Gale-Shapley(1962) / Irving(1985) 经典；「almost-stable」有 TSC 论文；「AI 室友匹配」有 IEEE 论文 + 央视调查 + 一批硕士论文。**不要在答辩里说「我们发明了稳定匹配」，一戳就破。**
2. **无完全重合**：这是唯一能站住的原创性主张，但它的形态是「组合 + 工程落地」，不是「发明某个部件」。
3. **「用了 AI」不是创新点**：单独拎出「LLM 打分喂相容度」没有任何创新，会被央视那篇一棒打死。「把 AI 用得诚实、可解释、可证明差距」才是。
4. **借鉴要「有创新点才行」→ 有，但要讲成「增量」**：评审认可的是「我们站在 Irving/Gale-Shapley/almost-stable 的肩膀上，做了这四件他们没有做的事」，而不是「我们比谁都聪明」。

## 5. 在结题材料里怎么用

- **申报书/结题报告「创新点」章节**：直接搬 §2 表格的四行，每行都写「借鉴什么 → 增量什么」。
- **答辩 PPT**：一页「一句话定位」（§1）+ 一页「四个增量」（§2 表）+ 一页「8 文献对照」（§3 表，标注哪篇只做哪个部件）+ 一页「诚实边界」（§4，主动自曝底层不原创，反而加分）。
- **被问「和 almost-stable 那篇（TSC）有什么不同」**：答「它做的是有界偏好表下的理论界，我们做的是带容量 4 宿舍约束下的可计算定义 + CP-SAT 量化间隙 + 可解释申诉 + 工程落地；我们把它当对照基线，不当对手」。
- **被问「AI 匹配不是被央视批形式主义吗」**：答「央视批的恰恰是我们不做的——假装精准的打分。我们的回答是 MAA：承认拿不准、给出可评估性门限、让学校知道哪些分数能信哪些不能信」（指向 `docs/创新点-不确定感知的宿舍分配.md` §8 的「evaluable=false 拒绝把分数当结论」）。
