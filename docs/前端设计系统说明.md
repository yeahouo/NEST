# NEST 前端设计系统说明（学工平台品牌）

> 适用版本：第二十轮艺术化重做之后的 30 个页面（P8 教学模块下线后删掉了 `admin-courses.html` / `checkin.html` / `course-detail.html` / `teacher-course-detail.html` / `file-preview.html` 五页；含学工 P10 新增的 `workstudy.html` / `workstudy-manage.html`、P7 新增的 `counselor-dashboard.html`、P6 新增的 `evaluation.html` / `eval-review.html`、P5 新增的 `award-punishment.html` / `award-manage.html` / `aid.html` / `aid-review.html`、P4 新增的 `leave.html` / `leave-review.html`、P3 新增的 `profile.html` / `counselor-students.html`）。本文只讲**前端长什么样、由什么构成、怎么改、怎么验**；
> 后端接口说明见《课堂管理系统-功能补全说明.md》，部署见《给学校的部署说明.md》，第三方库溯源见 `src/main/resources/static/libs/ART-LIBS.md`。

## 0. 三条不可动的政策

1. **品牌为「学工平台」**：顶栏品牌行固定为 `学工平台 <span>学生/辅导员/Admin</span>`（`.nx-brand`）。2026-10 按指导老师要求，由原来的 CodeClass 改为学工平台；宿舍三页的品牌行写成 `学工平台 <span>宿舍分配</span>`。
2. **只用有出处的现成设计，不自创**：所有视觉语言要么来自已 vendored 的开源库（daisyUI / Open Props / Radix Colors / Instrument Serif …），要么来自公开的 CSS 技法（发丝分隔、渐变底纹）。自己写的是**组合与编排**，不是新的设计体系。
3. **离线校内网、零 CDN**：字体、图标、脚本、样式全部落盘在 `src/main/resources/static/`。`file://` 直接打开会因 ESM/importmap 的 CORS 失败，必须经本地 HTTP 服务（部署说明里有现成的）。

## 1. 三层架构

| 层 | 载体 | 职责 |
|---|---|---|
| 令牌层 | `tools/webbuild/tailwind.config.js` + `libs/open-props` + `libs/radix-colors` | 颜色、圆角、阴影、间距的**唯一数值来源**；daisyUI 主题 `nestlight` / `nestdark` 也在这里定义 |
| 组件层 | `tools/webbuild/input.css`（`@layer components`，约 2,300 行，133+ 个 `nx-*` 类） | 按钮、卡、面板、刊头、发丝统计格、输入、弹窗、骨架屏等**全站同形**的积木 |
| 艺术层 | `static/css/nest-art3.css` + `static/js/nest-art3.js` | 按需启用的「灵动」效果：标题拆字、横向卡片行、列表增删动画、滚动进度；`prefers-reduced-motion` 或低配机自动整层关闭 |

产物只有一个：`static/css/nest.css`（约 149 KB，minify 后实测 152,223 字节），由 `tools/webbuild/build-web-assets.ps1` 生成；`nest-art3.css` 与 `nest-art3.js` 是独立文件，不参与 Tailwind 扫描。

### 颜色令牌（改色只改这里）

- 语义色由 daisyUI 主题给：`primary #3e63dd`、`secondary #8e4ec6`、`accent #b06000`、`success #2b9a66`、`warning`、`error #e5484d`；深浅两套在 `tailwind.config.js` 的 `daisyui.themes`。
- 中性面：`base-100`（画布）、`base-200`（卡面）、`base-300`（描边/缝）；文字用 `text-base-content`，次要文字用 `.nx-muted`。
- **换主题必须同时写三处**：`<html>` 的 `dark` 类（管 `--nx-*`）、`data-theme="nestlight|nestdark"`（管 daisyUI 组件）、`localStorage['nest-theme']`。`js/nest-ui.js` 的 `paintTheme()` 已同时写，页面内联的主题自举脚本也照抄这三行。

## 2. 版面公式（36 页统一）

每个内容页都是同一套「编辑部版式」：

```
nx-topbar（sticky 顶栏：品牌 + 返回/设置/登出）
└─ main：max-w-[1200px] mx-auto，纵向 gap-10
   ├─ header.nx-rise（底边发丝线）
   │   ├─ .nx-kicker        ← 例如 Admin / Courses
   │   ├─ h1.font-serif     ← Instrument Serif，text-3xl ~ text-6xl
   │   └─ 导语（.nx-muted）
   ├─ 数据区：grid grid-cols-N gap-px bg-base-300 rounded-box（**发丝缝**：格子自己用 bg-base-100 填色）
   ├─ 主内容：卡片用 `rounded-box border border-base-300 bg-base-200 shadow-xl`（daisyUI `card` / `card-body`）
   └─ 表单：`input input-bordered h-12` + `label-text font-mono text-[10px] uppercase tracking-[0.16em]` + 主按钮 `btn btn-primary`
```

- 圆角刻度固定：`rounded-box = 16px`、弹窗 `.nx-dialog = 22px`、按钮/输入统一胶囊或 10px（由 `--rounded-btn` 决定）；**不要在页面上手写 `rounded-3xl` 这类刻度**。
- 强调色只用于**状态与主行动**，四格统计里各用一个语义色（学生=success、教师=secondary、档案=warning）。
- 特殊页：`dorm.html`（自带手写样式表的功能自测台，令牌在页内 `:root`）、`art.html`（设计概念页，不参与站点导航）。（原先列在这里的 `file-preview.html` 已随 P8 教学模块一并删除。）
- 学工 P4 新增的两页（`leave.html` 学生请假/离校、`leave-review.html` 辅导员审批）完全套用上面的公式：刊头 + 发丝统计格 + `card` + `.tab-btn.nx-tab` 胶囊 + 驳回弹窗 `#reject-dialog`（遮罩与弹窗体是**同一个**元素：外层是 `.nx-scrim`，`firstElementChild` 才是卡片）。
- 学工 P3 新增的两页（`profile.html` 学生档案、`counselor-students.html` 辅导员名册）同样套公式：12 项档案 `dl` 用 `div > dt + dd`（探针读 `cells=12` 就是数 `dd`），名册详情弹窗 `#student-dialog` 与 `#reject-dialog` 同一写法 —— `.nx-scrim` 自身是 `display:block`，**打开时必须 `classList.add('flex')`**，否则 `items-center justify-center` 不生效、卡片铺满整屏。

## 3. 艺术层怎么用

只认属性、不认页面（`js/nest-art3.js`）：

| 属性 | 效果 | 用在 |
|---|---|---|
| `data-nx-split` | Splitting.js 拆字 + 逐字入场（2.5s 兜底必须显示） | 登录/注册/落地页等 h1 |
| `data-nx-carousel` | embla 轮播（拖拽惯性、边缘对齐、左右按钮） | `index.html` 的「Sourced parts」卡片行 |
| `data-nx-autoanimate` | auto-animate 列表增删过渡 | 工作台面板（`#leaves-container`/`#announcements-container`/`#awards-container`/`#aid-container`）、请假/资助/奖惩/勤工助学列表 |
| `.nx-scroll-progress` | 顶部滚动进度条 | 落地页 |
| `.nx-scrim` / `.nx-dialog` / `.nx-danger-soft` / `.nx-tile-icon` / `.nx-icon-ghost` | 弹窗遮罩、弹窗体、危险态、品牌渐变图标底、幽灵图标按钮 | 全站弹窗与操作区 |

**红线**：`prefers-reduced-motion: reduce`、`hardwareConcurrency <= 4` 或 `deviceMemory <= 4` 时，整层自动加 `html.nx-art3-off` 并且**所有入场初始态失效**——元素直接停在终态，绝不允许出现「opacity:0 的白屏」。加任何新动画时都必须遵守这条（终态写在基础 CSS，动画只放在 `@media (prefers-reduced-motion: no-preference)` 内）。

## 4. 改前端的工作流（务必按序）

```powershell
# 1) 改令牌或组件
tools\webbuild\build-web-assets.ps1          # 生成 static\css\nest.css，并校验 class 覆盖（要求 ALL HIT）
Copy-Item -Recurse -Force 'src\main\resources\static\*' 'target\classes\static\'

# 2) 静态检查（不需要浏览器）
node tools\check-dom-ids.mjs src\main\resources\static   # 36 页 / 814 个 id 引用必须 0 失配（参数是目录，传文件会 ENOTDIR）
node tools\check-hidden-display.mjs          # hidden 与 display 类不得互相打架
node tools\check-inline-js.mjs "<单个页面绝对路径>"   # 一次只接受一个路径
node tools\check-mapper-columns.mjs          # 实体/Mapper 字段与库表列对齐（后端改动后必跑；P12 后实测 20 实体 / 20 Mapper / 364 字段全可读）
node tools\page-contract.mjs --all --outdir target\page-contracts   # 版面契约；改动后要重生成并逐页 --verify

# 3) 真机验收（共享无头 Chrome 9222，**同一时刻只能跑一个探针任务**）
tools\check-unify.ps1        # 全站外形统一（圆角/按钮/遮罩/输入…，P13 后 12 页 24 项）
tools\check-redesign.ps1     # 36 页顶栏 + kicker + 无横向滚动（**只按 1440 宽验收**，1280/1366 要另用 target\diag-overflow.mjs 复核）
tools\check-motion.ps1       # 动效层（8 项）
tools\check-art-layer.ps1    # 艺术层生效与 SHA256 漂移守卫
tools\check-particles.ps1    # 粒子层（含 reduced-motion 退化）
```

改页面的通用做法：写一个 `target/apply-*.mjs` 转换脚本（**默认 dry-run，`--apply` 前备份到 `target\backup-*`**），脚本里必须带红线断言：`<script>` 数量、`id` 集合、行内事件多重集、业务函数名、接口引用、`setAttribute('data-theme'` 一处、art3 接线两处、无旧底色残留。红线不过就不许写盘。
页面 `head` 里的 PWA 三件套（`rel="manifest"` / 图标 / `/pwa.js`）**不要手改**：`node tools\wire-pwa.mjs`（幂等，`--dry` 预演）负责统一补齐——`/pwa.js` 按白名单只写 16 个学生端页，管理页不注册（离线壳不该替管理员下载工作台）。
本机**没有 git 仓库**，文件损坏只能程序化重建，所以备份是硬要求。

## 5. 已知取舍

- `art.html` 是设计概念页，故意不接入站点导航与顶栏体系。
- `dorm.html` 不引 `nest.css`（自测台页，样式自持），令牌与全站对齐靠页内 `:root` / `.dark` 覆盖块。
- 无独显老机的性能预算：主线程 JS ≤ 4 ms/帧、同页 canvas ≤ 2、粒子层 DPR 上限 1 且 fpsLimit 30、**绝不动画 blur 半径**、只动画 `transform`/`opacity`。
- 触摸目标仍有若干处小于 44px（设置页次要按钮、名册页小幅操作按钮等），属已知待办。
- 原生 `alert()` 报错的老路径已随 `teacher-course-detail.html` 一起删除（P8），现存页面统一用页内错误条 + 重试。
- **管理端顶栏在 1024–1439 宽只显示图标**（P10）：9 个入口全带标签时 1440 就会横向溢出，所以三个低频项（工作台总览 / NEST 宿舍分配 / 心理特征）的标签用 `hidden 2xl:inline`，窄屏退化为纯图标 + `title` 提示。这是刻意的取舍，不是漏样式；`check-redesign.ps1` 只在 1440 验收，1280/1366 的复核命令记在 `docs\学工平台改造路线图.md` §2.11（`target\diag-overflow.mjs`，可传 `OVF_W`/`OVF_H`）。

## 6. 改页面时的十个大坑（2026-10 学工 P11/P10/P8/P7/P6/P5/P4/P3 记录）

1. **`tools\webbuild\verify-css.ps1` 会把 JS 里的字面量当 class 名**（它除了扫 `class="..."`，还用 `className\s*=\s*([^;]+);` 与 `classList\.(add|remove|toggle|replace)\(([^)]*)\)` 抠单引号字面量）：
   - `classList.toggle('is-active', el.getAttribute('data-leave-filter') === v)` ⇒ 抽到假 class `data-leave-filter`；
   - `box.className = 'alert ' + (type === 'success' ? 'alert-success' : 'alert-error')` ⇒ 抽到假 class `success`；
   - `const className = document.getElementById('roster-class').value` ⇒ **局部变量同名**也中招，抽到假 class `roster-class`；
   - `classList.toggle('is-active', value === 'mine')` ⇒ 括号里的**比较式**同样中招，抽到假 class `mine`。
   修法：**先把属性读取落到变量**再去比较（`const key = el.getAttribute('data-x')`），**三元/等值判断先落布尔变量**再传（`const mineActive = value === 'mine'`），**别让局部变量叫 `className`**（用 `classFilter`），筛选器用 `.nx-tab` 而不是 `[data-x]` 属性选择器。否则 `build-web-assets.ps1` 直接 throw「有 class 没被生成」。
