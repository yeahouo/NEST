## B07 Fidan & Erdem 2021 · Knowledge-Based SRTI

**出处**：Müge Fidan, Esra Erdem. *Knowledge-Based Stable Roommates Problem: A Real-World Application.*
Theory and Practice of Logic Programming（投稿在审），arXiv:2108.04940v1 [cs.AI], 2021-08-10，18 页。
（PDF 原件：附件 `B07_Fidan2021_Knowledge-Based-SRTI.pdf`；纯文本转写：`target\paper-b07-srti.txt`，18 页 / 926 行。）

### 1. 它解决什么问题

经典 **Stable Roommates（SR）**：把 2n 个学生配成 n 对，每人对其他人有偏好序；解要**稳定**——不存在「互相都更想跟对方住」的阻塞对（blocking pair）。
本文用 SRTI（允许**并列** ties 与**不完整** incomplete 偏好表）作基础，指出这类问题在宿舍分配里真正缺的不是「域无关的公平准则」（Egalitarian / Rank-Maximal / Almost），而是**域知识**：学生问卷里的作息、整洁、吸烟、学习习惯等。

作者在其前作 **SRTI-ASP**（Erdem et al. 2020）上做了三处扩展，全部用 **Answer Set Programming（ASP, CLINGO 5.2.2）** 编码：

| 方法 | 偏好怎么表示 | 优化方式 |
|---|---|---|
| **Personalized-SRTI** | 每人对每个准则各有一个**选择**（如「我睡前在 12 点后」）+ 一个**重要性权重**（0 表示该准则对他无所谓）；按权重分层，同层里比「重合的准则数」 | 扩展偏好表 `≺''` 拼接「人对人的志愿表」与「准则型偏好表」，再跑 SRTI-ASP 求稳定解 |
| **Most-SRTI** | 只用**全体学生的准则重要性排序**（如问卷得出） | 在全部稳定解集合上**逐层**求最优：先让第 1 重要准则的总差距最小，在此条件下再优化第 2 个……用 ASP 的**分层弱约束**实现 |
| **Diversity 扩展** | 学校层面偏好 | 弱约束「跨专业同住加分」；硬约束 `forbidden(x,y)` 禁止某两人同住 |

### 2. 它的实测结论（原文数字）

**规模实验**（随机 SRTI 基准，n ∈ {40,60,80,100,150,200}，完整度 25% / 50%，每格 20 个实例，2–5 个准则，CLINGO 5.2.2 / Xeon W-2155 / 32 GB）：

| n | Personalized-SRTI 平均耗时（25% / 50%） | Most-SRTI 平均耗时（25% / 50%） |
|---|---|---|
| 100 | 2.469 s / 4.610 s | 0.353 s / 2.497 s |
| 150 | 14.556 s / 42.273 s | 2.331 s / 25.563 s |
| **200** | **51.640 s / 140.378 s** | **11.116 s / 104.921 s** |

他们还给出一个有意思的观察：加入准则知识会**自动提高**有效完整度（n×(d/100) + n×(1−d/100)×m/(m+1)，d=25、m=3 时理论 81%、实测 83%），所以「多加问题」并不只是让问题变难，也让偏好表变密。

**真实应用**（土耳其 Sabancı 大学，四轮问卷，累计 200+ 人）：
1. 第一轮 156 人（120 人住校）投票选问卷题目 → 选出 5 个准则；
2. 第二轮 81 人填偏好与重要性 → **全体重要性排序：吸烟 > 整洁 > 房间环境 > 作息 > 学习习惯**；
3. 用这 81 人的真实数据求一个「最优先准则稳定解」耗时 **4403.51 s（约 73 分钟）**；开 anytime 搜索时**首解 250 s**，其余时间都在做最优性检查；
4. 第三轮 59 人（分三组，三题）：多数题组里 73%–100% 的参与者选了算法给出的个性化稳定解；
5. 第四轮 42 人：**个性化稳定解 49% / 普通稳定解 29% / 不稳定解 22%** —— 论文据此论证「加入域知识有用」。

作者自己的总结也承认：Personalized 更尊重个体偏好，但 **Most-SRTI 计算上更快**（同样的解质量下时间少一个量级）。

### 3. 与我们 NEST 安居的逐项对照

| 维度 | B07（SRTI-ASP） | NEST 安居（本仓库） |
|---|---|---|
| 决策对象 | 室友**配对**（2 人一间，SRTI 是完美匹配问题） | **多床位房间 + 分块**（专业大类 × 性别 × 年级分块，块内分房，每间 4–6 人） |
| 输入 | 学生对每人的偏好序 + 每人对各准则的选择与权重 | **11 维观测特征**（作息、整洁、噪声容忍、社交、学习强度……），带噪声带缺失 → 相容度模型 |
| 目标 | 稳定性（无阻塞对）+ 分层优化准则 | 可加目标：相容度总和 − 木桶亏空平方（`RoomScorer.qualityTerm`），最大化 |
| 稳定性 | **形式化定义并作为硬保证** | 只有「阻塞对数」**指标**，且语义是「互相把对方列进不想同住」，**不是**偏好序意义下的阻塞对；算法第三步「阻塞对修复」是启发式近似，不保证为 0 |
| 多样性 | 弱约束（跨专业加分）+ 硬禁止 `forbidden(x,y)` | 有「公平差距」指标（各专业大类平均相容度极差），**没有跨专业混住的偏好项，也没有禁止同住约束** |
| 个体差异 | 每人对每个准则单独设权重（0 = 无所谓） | 权重是**全局**规则表，个体只贡献特征值 |
| 数据来源 | 真实问卷（81 人）+ 随机基准 | **合成数据 + 隐真值 `g`**（真实数据拿不到、且没有真值）；问卷缺失率作为实验因子 0%/25%/50% |
| 评估 | 主观问卷（49% vs 29%）+ 规模耗时 | 隐真值上的 7 个指标 + 配对检验（n=360）+ CP-SAT 最优间隙 |
| n=200 的代价 | **求一个稳定解**：51.6 s（Personalized）/ 11.1 s（Most） | **证明最优**：CP-SAT 1.6–4.1 s；NEST 求近优解 7–43 ms（间隙 2.54%） |
| 5000 人 | 未做（论文最大 200） | 主实验规模之一，平均耗时 **218 ms** |
| 技术栈 | ASP + CLINGO 二进制（声明式、外部求解器） | 纯 Java 17 + OR-Tools（仅离线评估时当裁判），可内网离线部署 |

一句话：**他们把「稳定性」做成了硬保证、把「域知识」做成了权重与准则排序；我们把「域知识」做成了特征模型、把「近似最优」做成了毫秒级启发式，代价是稳定性只剩指标、没有保证。**

### 4. 可以吸收的四点（按性价比排序）

**① 偏好型阻塞对作为可验证判据（成本最低、价值最高）**
增加一个指标：`偏好阻塞对数 = |{(x,y) | x 更想与 y 同住且 y 更想与 x 同住，但当前 x、y 不同房}|`。
它不需要改算法，只需在评估层用同一份问卷/志愿数据算一遍——就能在结题报告里写「我们的解在偏好意义下 X% 的实例阻塞对为 0」，这是审稿人能自己复核的硬指标，比现在的「互相拉黑数」更接近文献标准。
**注意**：这**不是**给现有「阻塞对数」改个名字，两者语义不同（现在是「不愿同住」，文献是「更想同住」），必须在文档里并列写清。

**② 每生权重（Personalized 思想）**
把全局权重表升级为 `w_i(学生) × sim_i(x,y)` 的逐生加权：每个学生在 11 维里各自勾选「最在意哪 2 项」。我们的 11 维问卷天然支持，且现有消融框架（`docs\实验与验证.md` §3）可以直接跑「全局权重 vs 每生权重」的对照实验，不新增基建。

**③ 硬约束「禁止同住」+ 软偏好「跨专业混住」**
学校现实中有：本人提出回避（曾与室友冲突、调解记录）、违纪关联、特殊健康需求。文献里就是 `forbidden(x,y)` 硬约束与跨专业弱约束。我们的分块策略本身按专业大类分块，一旦引入「跨专业混住」就与现有分块冲突，**需要先定政策口径**再谈实现——这是它进不了本轮的原因。

**④ 准则优先级的可配置化（Most-SRTI 的分层思想）**
把「学校最看重哪一维」做成管理端可配置的优先级序列（如某学年首查作息、次查整洁），解释层直接引用该配置。比逐生权重更省事，也更像「学校的决策」而不是「算法偏好」。

### 5. 为什么不能照搬

1. **技术栈**：ASP/CLINGO 是外部求解器（要分发二进制、内网离线、与现有 Maven 构建链无关）。我们用 CP-SAT 只做**离线裁判**，线上仍然纯 Java，这一点不能让出去。
2. **规模**：他们在 200 人上求一个稳定解就要 51.6–140.4 s，真实 81 人数据要 4403.51 s；我们每年几千人、要求一学期跑一次也不该等一小时。**稳定性的硬保证换不来这个代价**。
3. **口径差异**：SRTI 是「两人一间」的完美匹配，我们是「多床位分块 + 志愿/硬约束」；直接套模型会丢掉分块、性别、年级这些我校硬约束。
4. **结论不可直接引用**：他们的准则排序（吸烟最重要）是土耳其宿舍文化产物；主观问卷样本 42–59 人、单校。可以引用「域知识有用」这个结论，**不能**引用具体百分比当作中国高校的证据。

### 6. 写进结题报告的三种用法

1. **相关工作 / 方法对比**：用第 3 节表格，讲清「同一问题两种范式：声明式精确稳定 vs 启发式可扩展可解释」，我们在 n=200 上把「证明最优」压到 1.6–4.1 s、5000 人 218 ms。
2. **外部证据支持特征选择**：他们的调查显示学生最在意吸烟 / 整洁 / 房间环境 / 作息 / 学习习惯——与我们 11 维中的作息、整洁、噪声容忍、学习强度高度重合，可作为「问卷维度不是拍脑袋定的」的旁证（注明样本与国别差异）。
3. **诚实的边界**：明确写「我们不保证稳定」，并给出改进路径（第 4 节①），比含糊地说「算法考虑稳定性」更站得住。
