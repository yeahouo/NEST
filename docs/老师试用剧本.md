## 剧本 A · 学生视角（用 `chendw` 登录，约 10 分钟）

### A1. 登录 + 学生工作台（1 分钟）
- 操作：登录页输 `chendw / 123456`。
- 预期：进入学生工作台 `dashboard.html`，能看到「请假 / 综测 / 困难认定 / 资助 /
  勤工 / 奖惩 / 第二课堂 / 志愿服务 …」的模块卡片，以及顶部公告。
- 口径边界：工作台卡片是固定导航，不代表全部模块都对学生开放（哪些开放见各模块）。

### A2. 请假：提交一条请假（1 分钟）
- 操作：`/leave.html` → 填「类型 / 起止时间 / 事由 / 去向」→ 提交。
- 预期：台账里出现一条「待审批」；已有 3 条演示请假（2 条已取消/已销假、1 条待审）。
- 口径边界：请假类型与字段是学校自定，无官方出处。

### A3. 第二课堂成绩单：看学分与申报（1.5 分钟）
- 操作：`/second-class.html` → 看「成绩单 / 申报台账 / 学分汇总」。
- 预期：7 个板块（思想成长 / 志愿公益 / 实践实习 / 创新创业 / 文体活动 / 工作履历 /
  技能特长），5 场活动（如「新生入学教育主题讲座」「校园开放日志愿服务」），
  chendw 名下已有 2 条申报（1 条已确认、1 条辅导员已核）。
- 口径边界：**板块名称来自共青团中央「第二课堂成绩单」制度（中青联发〔2018〕5 号
  转载稿只给 7 个板块、无具体学分/学时数字）**；每板块的「必修学时 / 学年上限 /
  学分换算」系统一律显示「未设置」，等学校自己填，**绝不替学校补一个标准**。

### A4. 志愿服务：报名 + 工时（1.5 分钟）
- 操作：`/volunteer.html` → 看「可报名的项目」→ 报一个名；再看「我的工时」。
- 预期：4 个项目（「图书馆图书整理」已通过、「校园环境清洁」待审、「校运动会」
  已驳回、「社区邻里守望」草稿），报名后能登记工时。
- 口径边界：志愿服务是**独立台账**，与第二课堂「志愿公益」板块**不自动互转**——
  这是两本账，别指望报一次工时两边都涨。

### A5. 综测排名：看自己的排名（1.5 分钟）
- 操作：`/ranking.html` → 选批次 → 看 `M = A + B` 综合分与排名。
- 预期：3 个演示批次（草稿态）；王小明已有学习成绩 A（88 分）与若干条已审加分，但**排名明细此刻为空**——要等管理端「一键计算」才生成（见剧本 C）。
- 口径边界：综测公式 `M = A + B`、加分/扣分条目出自《厦门大学嘉庚学院优秀学生
  奖学金综合测评实施办法（2022年修订）》（系统 `RankService` 引用）；但**排名明细
  是运行时计算的**——学生页看到空明细，是因为要等管理端点「一键计算」（见剧本 C）。

### A6. 勤工助学：应聘一个岗位（1 分钟）
- 操作：`/workstudy.html` → 看岗位列表 → 应聘。
- 预期：3 个岗位（图书馆图书整理、教务处资料录入正在招人，后勤多媒体巡检待发布），
  已有 6 条申请。
- 口径边界：岗位、时薪、工时口径为学校自定。

### A7. 资助 + 困难认定 + 生源地贷款（1.5 分钟）
- 操作：`/aid.html`（资助）与 `/poverty.html`（困难认定）各点一遍；`/aid.html`
  下方「贷款登记」看生源地贷款。
- 预期：资助 35 条申请；困难认定有「公示中 / 已驳回」等多阶段；贷款 4 条
  （刘思琪待核验、陈德文辅导员已核、王小明已到账、赵小红退回待改）。
- 口径边界：贷款字段表**无官方出处**（学校自定）；困难认定等级由学校设定。

### A8. 荣誉 / 党建 / 心理（1 分钟，快速过）
- 操作：`/honor.html`、`/party.html`、`/psyche.html` 各扫一眼。
- 预期：荣誉有「2026届优秀毕业生评选」申报（陈德文已交、刘思琪被驳回、周杰草稿）；
  党建 3 条申请；心理有 4 条预约（王小明待确认、赵小红已确认、刘思琪已完成+再次预约）。
- 口径边界：荣誉/党建流程按一手通知原文建模；心理测评**量表与常模不可核实**（不编），
  只做预约与关注等级台账。

## 各模块口径边界速查表（诚实声明）

| 模块 | 能演示什么 | 不替学校拍板 / 未核实 |
|---|---|---|
| 第二课堂 | 7 板块 + 学分式申报 + 四级审核 | 学分/学时具体标准（显示「未设置」） |
| 综测 | `M=A+B` + 一键计算 + 公示 | 排名明细要运行时算，测评比例引用 2022 办法 |
| 志愿服务 | 项目 + 工时 + 审核 | 与第二课堂不自动互转 |
| 生源地贷款 | 提交→核验→确认→退回 | 字段表无官方出处 |
| 困难认定 | 多阶段认定流程 | 等级规则学校自定 |
| 心理 | 预约 + 关注等级 | 量表/常模不可核实，不编 |
| 宿舍分配 | 算法分配 + 可解释 | 不代表正式分房政策 |
| 荣誉/党建 | 线上申报 + 多级审核 | 流程按一手通知原文 |

## 数据复位（点乱了怎么办）

```powershell
# 在项目根目录（D:\project\NEST）执行，一键把演示数据恢复干净：
& .\tools\demo-seed.ps1
```

它会依次：清掉自动化测试残留 → 按序重灌 12 个 `sql/nest_*_demo.sql` →
打印每模块行数自检表（`tools/verify-demo.sql`，全 `OK` 即成功）。
重复执行不会重复插数据（每个脚本都先删自己的区间再插入）。

**单独核对数据是否齐**（只读）：

```powershell
cmd /c "mysql --defaults-extra-file=%TEMP%\nest_my.cnf -D nest -t < tools\verify-demo.sql"
```

## 常见问题

- **学生页综测明细是空的？** 正常——排名明细要管理端「一键计算」后才生成。
- **贷款区块是空的？** 跑一遍 `tools\demo-seed.ps1`（含 `sql/nest_loan_demo.sql`）。
- **只看到自己学生的数据？** 是数据级授权在起作用，换 `zhangsan` 登录会看到另一批学生。
- **账号密码？** 全部 `123456`。
- **某个数字和学校实际不符？** 那是演示数据；涉及真实口径的字段系统一律显示「未设置」，
  由学校在管理端自行填写，系统不越俎代庖。
